## 📌 프로젝트 개요

- 로봇 콘텐츠와 설정 데이터를 통합 관리할 수 있도록 구축한 ==로봇 콘텐츠 전용 관리자 시스템(CMS)==입니다.
- RCMS를 통해 장소·층수·지도 좌표·TTS 멘트 등 각종 콘텐츠에 관한 로봇별 주요 설정을 웹 UI에서 직접 관리할 수 있게 하여,  
  로봇 설정 ==효율성==과 ==안정성==을 크게 향상시켰습니다.
  - 기존에는 로봇별 설정을 직접 접근하여 JSON 파일을 수정해야 했기 때문에, 초기 설정 및 운영 과정에서 많은 시간이 소요되었습니다.
- 설정 저장 시 로봇 API와 연동되어 실시간으로 반영되며, 관리자는 별도 소프트웨어 설치 없이 ==브라우저에서 설정 변경==이 가능하도록 구성하였습니다.
- 이외에도 월별/일별 콘텐츠 ==사용량 데이터 시각화== 기능을 통해, 운영 데이터를 기반으로 한 콘텐츠 전략 수립이 가능하도록 하였습니다.

## 🧑‍💻 주요 기여

- RCMS 관리자 페이지 내의 [[로봇 설정]] 기능 및 [[데이터 시각화]] 기능을 개발하였습니다.
- 기존에는 각 로봇에 직접 접속하여 JSON 파일을 수정해야 했지만,  
  해당 프로젝트를 통해 [[UI 기반 설정]] 기능을 제공하여 [[초기 세팅 시간 50% 이상 단축]]하였습니다.
- 장소, 층수, 좌표, TTS 멘트 등 각 항목을 폼 요소로 구성하고,  
  설정 변경 시 API 호출을 통해 실시간으로 로봇에 적용되도록 구현하였습니다.
- 지도 기반 좌표 설정 기능을 제공하여, 관리자가 목적지를 시각적으로 설정할 수 있도록 하였으며,  
  [[비개발자도 손쉽게 설정]]을 조정할 수 있는 환경을 만들었습니다.
- 월별, 일별 콘텐츠 사용량을 시각화하기 위해 [[chart.js]] 를 도입하고,  
  막대 그래프와 선형 그래프를 통해 주요 지표를 직관적으로 확인할 수 있도록 구현하였습니다.
- 기존 RCMS에 로봇 설정 및 콘텐츠 운영 기능을 추가하여, [[관리자 시스템(CMS)]]의 효율성과 실용성을 높였습니다.
