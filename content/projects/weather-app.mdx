## 📌 프로젝트 개요

- 위치 기반으로 ==현재 날씨==, ==내일 날씨==, ==주간 예보==를 제공하는 콘텐츠입니다.
- 로봇의 대기 상태, 콘텐츠 메인 화면, 날씨 전용 화면 등 총 ==세 페이지에서 날씨 정보를 안내==하며,
- 콘텐츠 진입 시에는 ==TTS(음성 안내)==를 통해 사용자에게 자동으로 예보를 들려줍니다.
- 로봇 대기 상태 진입 시 일정 시간 간격으로 날씨 안내 TTS 를 통해 기상 예보를 제공합니다.
- 텍스트와 음성 안내는 ==국제화(i18n)==를 위해 ==다국어를 지원==하여, 다양한 언어 환경에서도 유연하게 대응합니다.

## 🧑‍💻 주요 기여

- 기획 단계부터 메인 개발자로 참여하여, 신규 콘텐츠를 [[단독으로 맡아 개발을 진행]]하였습니다.
- 날씨 콘텐츠가 대기 화면, 메인 화면, 날씨 전용 화면 등 다양한 위치에서 사용되는 만큼,  
  공통 컴포넌트와 데이터 관리 구조를 어떻게 가져갈지에 대해 많은 고민을 하였습니다.
  - [[아토믹 디자인 패턴]]을 참고하여, UI 컴포넌트를 기능 단위로 나누고, 상위 페이지에서 [[재사용성과 확장성]]을 고려한 구조로 설계하였습니다.
  - 기존 코드 구조와 정합성을 고려하면서, 컴포넌트의 책임과 위치를 어떻게 분리할지에 대해 여러 방안을 시도하고 조율하였습니다.
- 외부 기상청 API 연동 이후, 관련 규격을 내부 문서로 정리하여, 향후 다른 개발자도 쉽게 이해하고 수정할 수 있도록 [[문서화를 진행]]하였습니다.
- 기상청 API에서 간헐적으로 응답 오류가 발생해, Local Storage 기반의 [[캐싱 로직]]을 구현하였습니다.
  - 그 결과, 예외 처리 안정성을 높이고 API 호출 빈도를 하루 [[30회 -> 2회]]로 [[약 93% 줄이고]]  
    평균 로딩 시간을 [[1600ms -> 700ms]]로 [[약 56% 단축]] 할 수 있었습니다.
  - 이후 API 응답 관련하여 [[오류 발생 0건 유지]] 하였습니다.
- 언어에 따라 자동으로 콘텐츠 내용과 음성 출력이 전환되도록, [[국제화(i18n) 구조를 적용]]하여  
  다양한 언어 환경에서도 자연스러운 사용자 경험을 제공하였습니다.
