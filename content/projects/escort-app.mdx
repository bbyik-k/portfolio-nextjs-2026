## 📌 프로젝트 개요

- 로봇이 ==목적지까지 길안내==를 하며, 실시간 상태에 따라 사용자에게 ==음성 및 화면 안내==를 제공하는 경비 로봇 전용 서비스입니다.
- 이동 중 로봇의 ==실시간 위치와 상태== (대기, 이동, 도착, 혼잡, 경로 장애 등)를 UI로 ==직관적으로 표현==하며,  
  상황에 맞는 음성 안내를 함께 제공하여 보다 ==명확한 에스코트 경험==을 구현하였습니다.
- 로봇이 에스코트를 수행 중일 때는 메인 화면 이동 및 기타 콘텐츠 이용이 제한되며,  
  자동 복귀 이후에 정상적으로 사용할 수 있도록 설계하여 ==콘텐츠 안정성==을 높였습니다.
- 이동 시작, 일시 정지, 목적지 변경, 원위치 복귀 등의 이벤트 상태는 앱 전역으로 관리되며,  
  UI 콘텐츠 뿐 아닌 ==미들웨어에도 상태를 전달==하여 로봇 ==하드웨어의 움직임을 제어==합니다.
- 관리자 모드에서는 지도 ==UI를 통해 목적지 좌표를 직접 설정==할 수 있도록 구성하여 ==관리자 편의성==을 높였습니다.

## 🧑‍💻 주요 기여

- 에스코트 기능의 기획에 참여하고, 프론트엔드 개발을 [[단독으로 담당]]하였습니다.
- 신규 콘텐츠의 성공적인 시연 및 [[상용화]]를 이끌었습니다.
- 로봇 이동 중 발생하는 다양한 상태를 정의하고, 각 상태에 따라 UI와 음성 안내가 자연스럽게 전환되도록 [[상태 기반 UI 구조]]를 설계하였습니다.
  - [[MVC 구조]]를 기반으로 UI와 로직을 분리하고, 각 상태의 변경 및 추가가 용이하도록 [[State 패턴]]을 적용하여 다양한 [[상태를 관리]]하였습니다.
  - 로봇 상태에 따라 분기되는 다양한 로직을 단순화하고, 결합도를 줄이기 위해 [[Facade 패턴]]을 적용하였습니다.
- 상황에 맞는 [[TTS]] (Text-to-Speech) 음성 안내를 실시간으로 동기화하여,  
  사용자에게 [[명확한 안내]]가 전달되도록 구현하였습니다.
- 로봇의 현재 위치 정보를 [[WebSocket]] 기반으로 수신하고, 지도 UI 상에 위치를 동적으로 반영하는 기능을 개발하였습니다.
- 전체 기능에 대해 반복적인 [[테스트와 리팩터링]]을 거쳐, 현장 시연에서 [[안정적]]이고 [[완성도]] 높은 결과를 도출하였습니다.
- 해당 프로젝트는 경비 로봇 [[서비스를 확장되는 계기]]가 되었으며,  
  이후 2년간 총 14개 고객사 건물에 도입되어 [[비즈니스 모델로 안착]]하는 데 기여하였습니다.
