## 📌 프로젝트 개요

- 대량 문자 전송 플랫폼의 운영 효율을 높이기 위한 ==관리자 전용 데이터 관리 시스템==입니다.
- 문자 송신 ==통계==, ==사용자 관리==, ==실시간 잔액 확인==, ==코인 충전== 등의 기능이 구현되어 있습니다.
- 주요 기능을 한눈에 볼 수 있는 ==대시보드 중심==의 관리자 UI로 구성되어 있습니다.
- 사용자 인증부터 데이터 시각화, ==Excel 다운로드==, REST API 연동 기능이 포함되어 있습니다.

---

## 🧑‍💻 주요 기여

- 고객 요구사항 정리 및 [[WBS]] (Work Breakdown Structure) 작성, 일정 관리 등 [[프론트엔드 기획]]과 프로젝트 진행 전반을 직접 담당하였습니다.
  - 고객사 요구사항에 따라 빠른 피드백과 수정이 반복되는 외주 프로젝트 환경에 유연하게 대응하였습니다.
- [[React.js]]와 [[Material-UI]]를 활용하여 관리자 페이지 UI를 개발하고, [[반응형 웹]] 환경에서 다양한 디바이스 대응이 가능하도록 구현하였습니다.
- 백엔드 개발자와 협업하여 [[REST API 설계 구조를 정의]]하였습니다.
- [[CORS]], [[credentials 처리]], [[preflight 요청]] 등 [[cross-domain 이슈를 해결]]하며 안정적인 데이터 연동을 구현하였습니다.
- [[Nivo Chart]]를 활용하여 문자 송신 데이터를 선형, 원형, 막대 그래프로 시각화하였습니다.
- [[xlsx 라이브러리]]를 통해 엑셀 다운로드 기능을 제공하여 관리자 편의성을 향상시켰습니다.
- 세션 기반 [[로그인]] UI와 인증 처리, [[실시간 잔액 확인]] 및 사용자 [[코인 충전 기능]]을 구현하여 사용자 관리 기능을 제공하였습니다.
